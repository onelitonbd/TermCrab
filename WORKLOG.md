  - **টাইপড wire:** প্রতিটি SSE frame এখন `{v: 1, seq, ts, type, …}` — ক্লায়েন্ট "আমি v1 বুঝি" বলতে পারে, seq থেকে হারানো frame ধরা পড়ে, আর type সবসময় নিরাপদ token (case অপরিবর্তিত, নাহলে প্যানেলের `thinkingCaps`/`canvas:update` ভাঙত)। দশটা family কোডে ঘোষিত এবং `docs/API.md`-এ আয়নায় লেখা; টেস্ট সোর্স স্ক্যান করে, তাই নতুন event type ডক না লিখে ship করা যায় না।
  - **Idempotency:** `POST /api/chat`-এ `Idempotency-Key` (header বা body) দিলে সেটা একদিন মনে রাখা হয় — ফোনের নেটওয়ার্ক ফেল করলে retry একই `turnId` ফেরত দেয় (`replayed: true`), দ্বিতীয় turn চালায় না। ভুল body হলে `400 {error, field}` — কোন ফিল্ড ভুল, সেটা বলে।
  - **Rate limit:** প্রতিটি key-তে (ডিভাইস / মাস্টার টোকেন / peer ঠিকানা / প্রতিটি চ্যানেল চ্যাট) token bucket; `gateway.rateLimit = {perMinute, burst}` (ডিফল্ট 60/10)। বাকেট শেষ হলে সাথে সাথে `429 {error, retryAfterMs, limit}` + `retry-after` header, আর চ্যানেলে ফিরে যায় এক বাক্য — আরেকটা turn queue-তে না ঢুকে। বাজে config clamp হয়, সব আটকে দেয় না।

## 6. Rules this file follows (so it stays honest)

1. **No test, no "done".** A step moves to ✔ only with a named test that fails without the change.
2. **No date promises.** Sizes are in focused days; order is fixed, calendar is not.
3. **Stale is loud.** `status.mjs` reports how many commits landed since this file was last updated. Zero is the only healthy number: it prints `STALE` and exits non-zero otherwise, and `test/worklog.test.ts` asserts it — so a commit that skips the tracker fails the suite.
4. **One screen.** If this file grows past a screen of current work, the history moves to §4 and §2 stays small.
5. **Every commit touches this file.** Either it updates §2 (the batch moved) or §4 (a batch shipped). That is what keeps the count at zero without remembering to do it.
